# IMDb Movies Dashboard

An interactive Power BI dashboard exploring movie ratings, genres, and release trends across thousands of IMDb titles.

## Overview

Built to practice data visualisation with a rich public dataset. The dashboard lets you explore which genres dominate by rating, how average scores have shifted over decades, and which films sit at the top of each category.

## Tech Stack

| Tool | Role |
|---|---|
| Power BI Desktop | Dashboard design and publishing |
| CSV (IMDb dataset) | Data source |
| DAX | Calculated measures and KPIs |

## What's in this repo

| File | Description |
|---|---|
| `IMDb Dashboard.pbix` | Power BI project file — open in Power BI Desktop |
| `IMDb_All_Genres_etf_clean1.csv` | Cleaned IMDb dataset used as the data source |

## How to open

1. Install [Power BI Desktop](https://powerbi.microsoft.com/desktop/) (free).
2. Open `IMDb Dashboard.pbix`.
3. The CSV data source is bundled — the dashboard should load without reconfiguration.

## Skills demonstrated

- Data import and transformation in Power Query
- Dashboard layout and visual hierarchy
- DAX measures for dynamic KPIs
- Slicers and cross-filtering for interactivity
